## Most-Worked Project

### [Friday](https://github.com/moudook/App_dev) — Android AI Assistant
This is where most of my actual hours have gone. Android client (Kotlin/Jetpack Compose) talking to an LLM backend.

- **Shake-to-clear:** shake the phone and whatever you just typed is completely removed from AI processing — nothing gets sent or logged. This is a real, working feature.
- An in-progress branch streams an OpenCode CLI plugin's internal reasoning (thinking/tool calls/steps) live into the Android UI over a WebSocket bridge — partially working, not fully stable yet.

`Status: actively developed, most mature repo I have`

## Not Public (by design)

I built a fairly thorough deep-research system on top of OpenCode CLI — comparable in spirit to Gemini's Deep Research. It's for personal use only and I'm intentionally **not** open-sourcing it, since a public release could make it easier to misuse for research/scraping abuse. No repo link — this is staying private.
